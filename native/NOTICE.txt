SceneSense Native Matting
Local Windows x64 OBS 33 filter source: GPL-3.0-or-later.
Source: native/scenesense-matting.c in the SceneSense project.

Runtime and model dependencies, not included in the C source:
- Robust Video Matting by Shanchuan Lin et al., official MobileNetV3 FP32 ONNX
  model v1.0.0; GPL-3.0. https://github.com/PeterL1n/RobustVideoMatting
- ONNX Runtime 1.23.0, Microsoft; MIT.
  https://github.com/microsoft/onnxruntime/tree/v1.23.0
- Microsoft DirectML runtime; Microsoft distribution terms.
  https://github.com/microsoft/DirectML
- OBS headers from the official 33.0.1 tag; GPL-2.0-or-later.
  https://github.com/obsproject/obs-studio/tree/33.0.1

This is a local prototype installation, not a signed release installer.
Retain the upstream license texts, model notices and corresponding source
when preparing a distributable release.
